# Frontend

React, TypeScript, Vite, and Tailwind CSS frontend for the Expense Tracker.

Run `npm install` followed by `npm run dev` from this directory.

Configure `.env` from `.env.example`. `VITE_API_URL` is the backend base URL, `VITE_USER_ID` is the temporary user context used until authentication is implemented, and `VITE_CATEGORY_OPTIONS` maps category labels to existing database category UUIDs.
